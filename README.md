# Oone-Click-App-OMMD-

Oone Click App V.2.2.12 (OMMD) animated field-operations presentation and interactive HTML form sample generated from the four Oone Click App PDF manuals.

## Deliverables

- **Animated Presentation (`Oone_Click_App_Presentation.html` / `/` on Vercel)**: 9-slide interactive deck covering Check Load Profile, Verify Device, Commission Meter, Decommission Meter, live HTML form playground, and Smart Meter OMMD ecosystem diagram.
- **Standalone Interactive HTML Form Sample (`Oone_Click_Form_Sample.html` / `/form` on Vercel)**: Live animated mobile preview, validated inputs, realistic execution toasts, and copyable HTML/CSS form source.
- **Extracted Manual Screenshots (`pdf_images/`)**: 13 real UI captures extracted from the PDF operation manuals.

## Controls & Languages

- **Default Language**: Khmer (`KH`)
- **Switch to English**: Click the `KH / EN` switcher, press `L`, or append `?lang=en` to the URL
- **Navigation**: Arrow keys (`Left` / `Right`), `Space`, on-screen buttons, `T` for Light/Dark theme, `F` for Full screen
